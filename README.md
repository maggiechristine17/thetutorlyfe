# thetutorlyfe.com

The main website for The Tutor Lyfe: `index.html` plus the `img` folder.

Cloudflare (Worker `square-feather-ec59`) deploys this site automatically whenever `main` changes. Settings are in `wrangler.jsonc`; files listed in `.assetsignore` are not published.

The booking pages and dashboard (api.thetutorlyfe.com) live in the separate repo `api.thetutorlyfe`.
